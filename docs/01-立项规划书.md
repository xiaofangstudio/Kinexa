# 01 · 立项规划书

> 小方工作室 · Kinexa ｜ 版本 `v1.0` ｜ 2026-10-07

## 一 定位

Kinexa 是二维动画与矢量动画软件，对标 Adobe Animate。

它在创作线里的位置很清楚：**负责把角色画动。** Reelix 负责把画好的东西剪成片子、合成进镜头。两者不重叠。

三块能力，按重要性排序：

| 序 | 能力 | 说明 |
| --- | --- | --- |
| 1 | 逐帧绘制 | 二维动画的根。画笔、橡皮、图层、洋葱皮、帧管理 |
| 2 | 矢量动画 | 路径与锚点、钢笔、形状、填充描边、补间 |
| 3 | 绑定与调度 | 骨骼绑定、口型、镜头调度 |

## 二 为什么现在做

创作线八款里，真正能整包拿来二开的只有三个，Kinexa 是其中之一。底座 OpenToonz 与 Tahoma2D 都是 BSD-3-Clause，允许改造并入，改造量小于从零自研。

其余几款要么底座是 GPL 只能隔着进程看，要么根本没有底座。Kinexa 属于底座宽松的那一类，工期可以按改造估算，不必按自研估算。

## 三 明确不做什么

以下方向砍掉，不排期。

- **不做三维。** 三维归 Reelix 的空间识别与合成。
- **不做视频剪辑。** 剪辑是 Reelix 的附属能力，Kinexa 只导出素材。
- **不做音频编辑。** 归 Timbra。
- **不做位图精修。** 归 Strata。Kinexa 的位图能力只服务于逐帧绘制。
- **不做 AI 上色与智能补间。** 产品线整体无 AI。
- **不做云端协作与账号体系。**

## 四 硬指标

全部为可测量值，测不出来的一律不算。

| 项 | 指标 |
| --- | --- |
| 交付体积 | ≤ **112.5MB**（Reelix 150MB 的 3/4） |
| 冷启动 | 空项目双击到画布可用 ≤ 3s |
| 笔迹延迟 | 落笔到屏幕上出现线条 ≤ **16ms** |
| 空闲内存 | 空项目 ≤ 400MB 私有工作集 |
| 洋葱皮 | 前后各 5 格，开启后笔迹延迟仍 ≤ 20ms |
| 画布缩放 | 100% 到 1600% 平滑，缩放过程不掉帧 |
| 逐帧回放 | 24fps 播放 500 格序列不丢帧 |
| 撤销 | ≥ 200 步，连续 30 次操作可全退回 |
| 导出 | 1080p 序列帧导出 ≥ 5 帧/秒 |
| 常驻 | 关窗后进程数 **0** |
| 联网 | 抓包请求数 **0** |

## 五 里程碑

一次只推一个，全部验收项打勾才能进下一个。

### M0 · 骨架能跑

- [ ] Tauri v2 工程初始化，dev 端口 1423
- [ ] `tokens.css` 落地，配色与 [02-优化与手感建议.md](02-优化与手感建议.md) 一致
- [ ] 画布区、图层面板、时间轴三区布局
- [ ] Rust 侧：`new_project` / `save_project` / `load_project`
- [ ] 前端：能在画布上画出一笔，笔迹平滑无锯齿

### M1 · 逐帧能画

- [ ] 画笔（压感、大小、硬度、不透明度）与橡皮
- [ ] 图层增删改、图层顺序、图层可见性与锁定
- [ ] 帧管理：新建、复制、删除、拖动重排
- [ ] 洋葱皮：前后格数、着色区分前后
- [ ] 撤销重做覆盖全部绘制与帧操作
- [ ] **验收**：笔迹延迟 ≤ 16ms，画 100 笔不卡

### M2 · 矢量能用

- [ ] 路径、锚点、贝塞尔手柄
- [ ] 钢笔工具、形状工具、填充与描边
- [ ] 路径与逐帧图层可互相转换
- [ ] **验收**：画一个矢量角色，锚点可精确拖动，填充跟随路径实时更新

### M3 · 动起来

- [ ] 补间：位置、缩放、旋转、透明度
- [ ] 骨骼绑定与形变
- [ ] 口型表与音轨对齐
- [ ] 时间轴：关键画格、缓动曲线
- [ ] **验收**：做一个 5 秒角色走路循环，导出播放流畅

### M4 · 能交付

- [ ] 导出序列帧（PNG / WebP）
- [ ] 导出视频（走 FFmpeg 动态库）
- [ ] MSI 打包，体积 ≤ 112.5MB
- [ ] 首启向导
- [ ] **验收**：干净 Windows 11 上安装、启动、卸载全流程无报错，抓包零网络请求
