# Kinexa 界面硬标准

这份文件是 Kinexa 界面改造的**硬标准清单**。它不是建议，是验收口径。
任何界面改动开工前先读一遍，收工前逐条自查。与 [AGENTS.md](../AGENTS.md) 同级有效。

> 它存在的唯一原因：这些规则已经被违反过（工具轨一度全变成中文单字、用过底座老图标）。
> 写下来是为了不再重复。

---

## 一、图标

1. **工具轨一律是图标，禁止文字。** 不许用中文单字、单字母、缩写当图标，也不许"图标不够就用字凑"。
   中文名只出现在悬停 tooltip 与右面板"工具选项"标题里。
2. **图标必须自绘。** 用 QPainter 矢量绘制，统一 24×24 网格、中心 (12,12)。
   **禁止**直接摆 OpenToonz 的 `tnztools/Resources/*.png`——那套是 2010 年代的位图，和本软件 UI 不是一路。
3. **图标风格**：单色墨线，笔画 1.6px 圆头；未选中 `#3B362D`，选中态 `#3B362D` 描边 + 暖黄底 `#FDF3D6` + 边框 `#E0C377`。
   一只图标内部最多用一个实心小色块做强调（暖黄 `#FFE29A`），不许出现第二种强调色。
4. **可读性下限**：30×30 按钮、图标主体占 18~20 区域、实际像素 100% 与 125% 缩放都要能认出轮廓。
   认不出的图标必须重画，不许靠 tooltip 兜。
5. **一个工具一个图标**，不许两个工具共用同一个图形；形态相近的工具（画笔/绘刷）要能一眼区分。

## 一·补、顶栏导航

顶栏菜单是**纯文字导航**，和 Strata / Vexa / Groma 一致：点击文字就地弹出菜单，**不许出现下拉小三角**（Qt 的 `QToolButton::setMenu` + `InstantPopup` 会画出那个箭头，禁止使用）。菜单文字之间间距收紧到 18~24px，不要做成间隔很宽的一排按钮。

## 二、密度与尺寸

| 部位 | 尺寸 |
| --- | --- |
| 顶栏 | 高 40 |
| 工具轨 | 宽 84，两列，按钮 30×30，间距 3 |
| 右面板 | 宽 262，内边距 12/10 |
| 时间轴 | 高 108 |
| 状态栏 | 高 26 |
| 基准字号 | 12px，字段标签 10.5px，提示 10px |

窗口默认 1280×832。任何控件不许溢出父容器，右面板滑块必须撑满可用宽度。

## 三、配色

唯一权威：暖黄 + 白 + 墨。状态色只准用在状态上。

- 墨 `#221F1A` · 纸 `#FAF8F3` · 线 `#E2DCD0` · 品牌 `#FFE29A` · 品牌线 `#E0C377`
- **严禁紫色、蓝紫、黑紫**；严禁第二强调色。
- 图标与文字不使用品牌黄当主色（黄只做选中底与强调点）。

## 四、文案

- 全中文、动宾结构、不用「请」开头：`导出序列帧` 而不是 `请导出您的序列帧`。
- 界面里不出现英文残留（工具 id、快捷键提示除外）。
- 图标不承载文字，文字不冒充图标。

## 五、自检清单（每次界面改动后逐条过）

- [ ] 工具轨 26 个工具全是自绘图标，没有一个字
- [ ] 没有使用 `Resources/*.png` 老图标
- [ ] 选中态暖黄底 + 墨描边，无第二种强调色
- [ ] 100% 与 125% 缩放下图标可辨
- [ ] 右面板无溢出，滑块撑满
- [ ] 无紫色、无第二强调色、无英文残留
- [ ] 截图自检通过后才汇报
