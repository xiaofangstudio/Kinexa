# Kinexa 功能进度（0.3.0）

以 OpenToonz 源码为内核（BSD-3-Clause），界面为 Kinexa 自有实现。本文只记"真正接通内核"的功能，不做口头清单。

## 一、绘制

| 功能 | 接线方式 | 状态 |
| --- | --- | --- |
| 26 种绘图工具 | `TApp::getCurrentTool()->selectTool()`，工具轨图标全部 QPainter 自绘 | 通 |
| 工具选项面板 | 按当前工具真实 `TPropertyGroup` 动态生成滑块（Visitor 识别属性类型，中文名映射，同名去重） | 通 |
| 色板 | 读当前 `TPalette`，9 色默认调色板，点击切 `setStyleIndex` | 通 |
| 逐帧画格 | 当前帧新建画格，层从 xsheet cell 反查（避开失效的 currentLevel 句柄） | 通 |
| 洋葱皮 | `OnionSkinMask::enable/mos`，视图菜单可勾选 | 通 |

## 二、图层与时间轴

- 图层列表读真实 `TXsheet` 列；点击切当前层，眼睛切 `setCamstandVisibility`，右键删除列。
- 时间轴多轨：每列一条轨，真实有画记号，点击同时切帧与切列，播放头随帧移动。
- 场长可设（播放菜单「设置场长…」），新建工程自动建一层。
- 播放/暂停真实循环推进（QTimer 按场景帧率），按钮切 ▶ / ❚❚。

## 三、工程与导出

- `.kin` 工程保存/打开：`ToonzScene::save/load`。
- 导出 PNG 序列帧：白底与透明底两种，1920×1080，按实际画格逐帧合成所有列。

## 四、快捷键

空格播放/暂停，←/→ 上一帧下一帧，Home 回首帧，Ctrl+Z / Ctrl+Shift+Z 撤销重做，
B 画笔 E 橡皮 F 填充 V 选择 T 打字 H 抓手，Ctrl+0 适配画布 Ctrl+1 实际像素 Ctrl+± 缩放。

## 五、MCP（15 个工具）

`kinexa_info` `kinexa_status` `kinexa_set_tool` `kinexa_set_frame` `kinexa_new_layer`
`kinexa_new_cell` `kinexa_save` `kinexa_open` `kinexa_export`（含 `transparent`）
`kinexa_screenshot` `kinexa_play` `kinexa_prev_frame` `kinexa_next_frame` `kinexa_undo` `kinexa_redo`

## 六、还没接的（按优先级）

1. 视图视觉：相机框 / 安全框 / 网格开关。
2. 时间轴横向滚动与帧标尺缩放。
3. 图层重命名、拖动排序、复制层。
4. 矢量层（PLI）与补间、骨骼（OpenToonz 的 Plastic / Skeleton 工具已在内核，需补界面入口）。
5. 导出 MP4 / GIF（需内置 ffmpeg 或调用外部）。
6. 色板编辑（增删色、改色）与调色板存储。

## 0.3.1 追加（2026-11-28 续补）

- **修掉截图错位/裁切的根因**：`captureWindow()` 原来用 `QScreen::grabWindow(winId())`，在远程/无显示会话下会把别的内容合成进来，导致右面板重复、色板被裁。改为 `QWidget::grab()` 由 Qt 自己渲染控件树，尺寸与内容一致。
- **色板改为自绘条**（`KxSwatchBar`）：一排 4×2、8 个色块，点击按坐标反算序号，不再依赖布局摆位；右键可「改这个颜色…」「新增一个颜色…」（走 `TPalette::setStyle` / `addStyle`）。
- **图层右键三件事**：重命名图层、复制这个图层（把当前列所有画格搬到新列）、删除图层。
- **时间轴缩放与横向滚动**：滚轮左右平移，`Ctrl`+滚轮改每格宽度（10–56 px），点格反算已补偿滚动偏移。
- **导出视频（MP4）**：文件菜单新增「导出视频（MP4）…」，按场长导白底 PNG 序列后调系统 PATH 里的 ffmpeg 编码 H.264；MCP 增 `kinexa_export_video`。实测 1920×1080 / 24 fps / 48 帧 / 2.0 秒。
- **导出序列帧改为按场长出图**：场长 48 帧时就导 48 帧，缺内容的帧给空白，不再只导到最后一个有画的帧。

## 0.3.2 追加（2026-11-28）

- **新建矢量层（PLI）**：图层菜单 + MCP `kinexa_new_vector_layer`。矢量层用同一套 10 色调色板，画笔在矢量层画的是路径（实测能落线、能改色）。
- **洋葱皮可调**：视图 → 洋葱皮，可选前后各 1/2/3 帧（透明度 0.5）与关闭，取代原来只有一档的开关。
- **画布辅助线**：视图 → 相机安全框 / 三分线 / 网格（可叠加），自绘叠加层不吃鼠标事件；MCP `kinexa_guide`（1/2/4 位或，0 关闭）。按 16:9 在视口居中，适配画布时与画幅基本重合。
- **删除当前画格**：编辑菜单新增，走 `TXsheet::removeCells`。
- **图层上移 / 下移**：图层右键菜单，走 `TXsheet::moveColumn`。
- **版本号 0.3.2**（标题、场景标签、关于框三处同步）。

## 0.3.3 追加（2026-11-28）

- **图层拖动排序**：按住图层行拖到别的行，直接调 `TXsheet::moveColumn` 换位。
- **时间轴播放跟随**：当前帧跑出可视范围时，时间轴自动横向滚动，播放不再"跑丢"。
- **撤销/重做后刷新面板**：图层、色板、画布一起重画，不再停在旧画面。
- **复制上一画格到当前帧**：图层菜单新增，逐帧动画在上一张基础上改的标准操作。
- **导出 GIF（循环）**：12 fps、960 宽，palettegen/paletteuse 两段合成，MCP `kinexa_export_gif`。实测 960×540 / 24 帧。
- **MCP 等待窗口放宽到 3 分钟**：导出要跑几十秒，原来 3 秒超时会误报"界面没在运行"。
- 底座没有独立钢笔工具常量，矢量笔就是矢量层上的画笔，撤销了误加的 T_Pen/T_PolyLine 两项。

## 0.3.4 · 全窗假死修复（2026-11-28）

用户报：软件内鼠标永远十字形、任何点击无效（含标题栏三大金刚键）、右键强制结束不立即退出且黑屏卡死。

三个真实成因：

1. 辅助线叠加层最初做成画布 QOpenGLWidget 的子控件并加了布局，GL 事件循环与 Qt 布局互相驱动，整窗进不了事件分派，光标停在工具十字上。
2. 导出在 GUI 主线程整段死等（逐帧 1920×1080 合成 + `waitForFinished(600000)`），窗口被判无响应；此时强制结束，GL 上下文来不及收，黑屏。
3. 导出期间与 250ms 的辅助线跟随定时器重入，崩在 `Qt5Widgets.dll +0x74a0`（0xc0000005）。

处理：

- 辅助线改为挂在画布容器同层，`WA_TransparentForMouseEvents` 不吃鼠标，靠 250ms 跟随 + `raise()`；不再参与任何布局。
- 导出与 ffmpeg 等待改成小步事件泵（排除输入与 socket 通知），并加 `KxBusyGuard`（深度计数）冻结辅助线跟随时钟；`exportVideo/exportGif` 用 `KxFlagGuard` 防重入。
- `exportFrames` 只保留深度守卫、不做重入拦截，否则会被 `exportVideo` 的嵌套调用挡掉（曾经因此导出“成功但文件没更新”）。
- 启动装载几十秒期间把光标切成沙漏，避免用户误判成死机；试过在装载中插一次 `processEvents` 让窗口先绘制，实测会崩在同一偏移，已回退。

验证：导出 MP4（1920×1080 / 24fps / 48 帧）与 GIF（960×540）均成功，进程存活、`Responding=True`，导出后状态查询与整窗截图正常。

## 0.3.4 · 「鼠标十字、点哪都不灵」真凶定位（2026-11-28）

真因不是界面层，是底座在鼠**标离开画布的那一瞬间**空指针崩溃：

- `SceneViewer::leaveEvent → onLeave()` 里有一句 `CommandManager::instance()->getAction(MI_ShiftTrace)->isChecked()`。
- Kinexa 用的是自建主窗 `KxMainWindow`，没有像底座 `MainWindow` 那样把这条「Shift & Trace」命令注册成菜单动作，于是 `getAction()` 返回空，直接解引用 → `0xc0000005` @ `Qt5Widgets+0x74A0`（就是那条反复出现的崩溃偏移）。
- 现象就是：一进画布是画笔十字（正常），鼠标一动出画布整窗就没了响应，强杀不退出、留一片黑。

修法：

- 新增 `kxActionChecked(CommandId)`（`menubarcommand.h` 末尾内联），未注册的命令一律当「未勾选」。
- 替换掉同类裸解引用 12 处：`sceneviewerevents.cpp`（leaveEvent 等）、`frameheadgadget.cpp`、`xshrowviewer.cpp`、`viewerpane.cpp`、`tpanels.cpp`。
- 启动装载拆成三段 `QTimer`（建画布 → 建场景 → 补图层与焦点），每段结束回一次事件循环：**启动到可交互从 45 秒降到 5 秒左右**，装载期间不再像死机。
- 加单实例保护（命名互斥量 `Kinexa.SingleInstance.0.3`）：第二次启动只把已有窗口提到前面后退出，避免多开互相抢 IPC 名字、老窗口变僵尸。
- 加崩溃取证：未处理异常时把「模块+偏移栈」写到 exe 同目录 `kx-crash.txt`（dbghelp 运行时动态加载，不加链接依赖）；同时给构建加了 `/MAP`，地址能直接翻回函数。
- 新增 MCP 诊断命令 `kinexa_diag`：一次看清模态窗、鼠标抓取、光标形状、激活状态、收到鼠标次数。

验收：连续 3 轮「进入画布 → 按下拖动 → 抬起 → 移出画布 → 点顶栏菜单」，进程存活、`Responding=True`、画布留下笔画、无 `kx-crash.txt`。

## 0.3.5 · 补功能一批：时间轴能动、导出有口、图层能调（2026-11-28）

这一版不是修 bug，是把「只有画画」往真正的动画流程上补。

时间轴（`KxTimelineBar`）

- 画格可拖动移动：按下记源格，横向拖过半个格宽才判定为拖动，松手时源格清空、落到目标格，拖动中画虚线指示落点。实测把第 2 格拖到第 6 格，源变空、目标有画格。
- 双击空画格直接建画格（`newDrawingCellAt`，按帧与列传参），不用先跑去菜单点「新建画格」。实测双击第 2 格后帧号变 2/48、格子出现内容。
- 右键画格菜单补全：复制这一格 / 粘贴到这里 / 插入空画格 / 删除这个画格 / 用这一格填满本段剩余空位（做循环动画常用）。
- 画格改动后统一走 `onCellsChanged` → 刷新图层、时间轴、画布。

图层（`KxLayerRow`）

- 每行加自绘锁图标（`KxLockIcon`：锁梁半圆 + 圆角锁身 + 锁孔，锁定时填暖黄），点一下切换 `TXshColumn::lock()`，锁住后该层不可画。
- 右键加「图层不透明度…」，弹 0–100 输入，落到 `TXshColumn::setOpacity()`，改完立即刷新画面。

顶栏

- 缩放换成一组实体控件：`−` / 百分比 / `＋` / `适配`，走 `SceneViewer::zoomQt(中心, 倍率)` 与 `zoomQt(false,true)` 复位，百分比读 `getNormalZoomScale().a11`。

文件菜单

- 补上「导出 MP4 视频…」「导出 GIF 动图…」「另存为工程…」——之前这三个只有 MCP 能调，界面上根本点不到，是「只有画画」最硬的一处缺口。

播放菜单

- 新增「帧率」子菜单：12 / 24 / 25 / 30 fps，播放定时器与 MP4 导出同步使用该帧率，画布头标签实时显示。

帮助菜单

- 新增「快捷键一览」对话框（绘制 / 帧与播放 / 文件 / 编辑 / 视图五组），把散落的键位一次摊开。

底座改动：`sceneviewer.h` 把 `zoomQt(const QPoint&, double)` 从 protected 段移到 public（外壳需要按中心点缩放）。

验收：编译通过、启动 5 秒可交互；双击建画格、拖动画格两项在实机上用消息模拟验证通过，进程存活、`Responding=True`、无 `kx-crash.txt`。
