# 03 · 竞品研究与界面取舍

> 小方工作室 · Kinexa ｜ 2026-11-21
>
> 目的：OpenToonz 难用不是因为它功能弱，而是因为它把「生产线术语」直接摊在首屏。
> Kinexa 要保留它的底层能力，但把操作路径重写成「打开就会画」。

---

## 一 一句话结论

| 软件 | 值得学 | 不能学 |
| --- | --- | --- |
| OpenToonz | 逐帧 + 矢量混合、调色板、节点合成、扫描 | 房间/面板堆首屏、Xsheet 当主界面、术语先行 |
| Toon Boom Harmony | 左工具栏 / 中画布 / 下时间轴 / 右属性的固定骨架 | 节点树和绑定先露出来 |
| TVPaint | 笔感、洋葱皮、曝光表式时间、可自定义命令面板 | 老式小图标、密集浮动面板 |
| Clip Studio Paint | 干净时间轴、矢量图层、工作区预设、音轨 | 漫画/插画功能压过动画入口 |
| Krita | 笔刷引擎、洋葱皮、光栅+矢量混用 | 专业绘画参数全量外露 |
| Pencil2D | 新手路径短、界面克制 | 功能上限低 |

**Kinexa 的定位不是「汉化 OpenToonz」，而是「把 OpenToonz 的能力装进一个现代、克制、全中文的壳」。**

---

## 二 OpenToonz 的真实痛点

来自官方文档、用户评测与入门教程的共同反馈：

1. **首屏信息过载。** 房间（Rooms）、Xsheet、Level Strip、调色板、节点树同时出现，新手不知道先看哪。
2. **术语门槛。** Xsheet、Level、Palette、Plastic、FX Schematic 全部是生产线词汇，没有中文语境下的解释。
3. **图标小且无标签。** 大量工具只有图标，找不到功能只能翻菜单。
4. **汉化不彻底。** 社区版长期存在中英混排，菜单与提示对不上。
5. **默认布局不像现代软件。** Xsheet 放在右侧、工具栏在上方，与 Harmony/CSP 的「左中右下」直觉相反。
6. **缺少自动保存与崩溃恢复。** 用户评测里明确提到没有 autosave/backup，复杂工程容易白干。
7. **学习曲线极陡。** 官方与第三方都承认「没有教程几乎无法独立上手」。

这些不是「功能问题」，是**信息架构问题**。Kinexa 的改造重点因此放在：

- 首屏只给「新建 / 打开 / 最近」三件事；
- 进编辑后固定三栏 + 时间轴，工具一律「图标 + 中文名 + 快捷键」；
- 高级能力渐进披露，默认收起，需要时再开；
- 所有错误提示中文化，不甩英文堆栈；
- 自动保存与恢复列为下一优先级，不再让用户替软件记保存。

## 三 已经落地的界面原则

### 3.1 启动流程

`欢迎页 → 新建/打开 → 编辑壳`，关闭工程回欢迎页，不退出程序。

欢迎页只保留：

- 新建卡：预设、宽高、帧率、底色、实时预览、上手速记；
- 最近卡：本地最近工程，文件不存在的置灰；
- 打开条：选 `.kin`；
- 页脚：快捷键 / 关于 / 版本。

### 3.2 编辑壳

- 顶栏：品牌、工程名、菜单、撤销重做、缩放、主题、保存；
- 左：工具轨，当前可用工具只有画笔 / 橡皮 / 抓手；
- 中：画布，Checkboard 衬底、纸面居中、笔尖圈；
- 右：图层 + 画笔属性；
- 下：时间轴与画格；
- 底：状态栏，当前工具提示 + 尺寸 / 帧率 / 画格 / 缩放。

### 3.3 可自定义，但不做「设置地狱」

「视图 → 界面设置」只有四项：

| 项 | 选项 | 默认 |
| --- | --- | --- |
| 主题 | 浅色 / 深色 / 跟随系统 | 浅色 |
| 界面密度 | 舒适 / 紧凑 | 舒适 |
| 轻磨砂 | 开启 / 关闭 | 开启 |
| 后续工具 | 收起 / 显示 | 收起 |

偏好存本机 `localStorage`，不上传、不联网。低配机器关掉磨砂即可换帧率。

### 3.4 视觉语言

- **主面白，主色奶油暖黄。** 浅色以白为主，暖黄只落在主按钮、品牌标与选中态；文字用中性暖灰，不用棕金。品牌奶油黄 `#ffe29a`，文字琥珀 `#7a5a00`。
- **严禁黑紫、蓝紫与任何紫色。** 深色模式是中性炭黑 `#161616` / 面板 `#1e1e1e`，不发紫、不发棕金；强调奶油黄 `#ffe29a`。
- 圆角：6 / 8 / 12 / 16 / 999。
- 1px 描边分区，轻阴影，不用重渐变。
- 轻磨砂只作用于顶栏、工具轨、面板、时间轴，**不作用于画布**，避免影响笔迹判断；面板 72% 半透明、18px 模糊，低配可一键关闭。
- 深浅两套都由 `tokens.css` 派生，组件不写死颜色。

**与同门软件的统一性：** 统一的是骨架，不是色相。Kinexa 与 Strata 共用同一套交互骨架——欢迎页 → 编辑壳、三栏布局、1px 描边、6/8/12/16/999 圆角、浅色默认 + 深色可切、图标必带中文名。颜色按产品分配：Strata 蓝、Reelix 绿、Kinexa 暖黄；这样并排打开时是一家人，又不会认错软件。

## 四 功能路线：先补「停不下来」的，再补「强」的

### 已落地（M0 范围内提前做）

- 画笔 / 橡皮 / 抓手、缩放平移、撤销重做；
- 图层增删、显隐、锁定、不透明度、改名、缩略图；
- 画格新建、复制、切换；
- 洋葱皮基础版：前一格红、后一格蓝，Rust 侧合成；
- `.kin` 保存 / 打开，背景色不烘进图层；
- 主题 / 密度 / 磨砂 / 后续工具四项自定义。

### M1 优先补

1. **自动保存 + 崩溃恢复**：每 2 分钟写 `.autosave`，下次打开提示恢复；正常保存后清理副本。
2. **帧管理补全**：删除画格、拖动重排、画格时长（一张画格停 2/3 格）。
3. **洋葱皮完整版**：前后各 1–5 格、只显示当前图层、红/蓝/绿三色可调。
4. **画布翻转**：水平翻转查看，专治「画歪了看不出来」。
5. **播放预览**：按 fps 循环播放，先支持短序列。
6. **工作区预设**：绘画 / 动画 / 清稿三套布局，一键切换。

### M2 矢量与「强」

- 钢笔、形状、填充、描边；
- 矢量图层与锚点编辑；
- 参考图 / 透光台（导入图片垫底，不参与导出）；
- 标尺、透视辅助、对称绘制。

### M3 动起来

- 补间、骨骼、口型；
- 摄影机 / 多平面镜头；
- 音频导入与波形（只做对位，不做音频编辑）；
- 序列帧与视频导出。

### 明确不做

- 节点合成当主界面（可做高级面板，但不进首屏）；
- Xsheet 作为默认时间轴（可提供切换，不强迫）；
- AI 补间 / 自动上色 / 大模型；
- 账号、云同步、联网校验、自动更新；
- 视频剪辑与音频编辑（分别归 Reelix / Timbra）。
