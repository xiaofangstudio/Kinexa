# 🎨 Kinexa

**二维动画与矢量动画软件。** 对标 Adobe Animate，管逐帧绘制与矢量动画这两件事，负责把角色画动。

## ✏️ 一句话说清做什么

三件事：**逐帧画、补间动、骨骼绑。**

- **逐帧**是二维动画的根，必须做到笔迹零延迟
- **补间与骨骼**是效率工具，让人不用一帧一帧磨
- **口型与镜头调度**是把动画变成片子的最后一段路

## ❓ 常见问题

**和 Reelix 什么关系？**
兄弟产品。Kinexa 画动，Reelix 剪合成，素材无缝交接。

**为什么选 OpenToonz 当底座？**
老牌开源动画软件，BSD 宽松许可允许改造并入，逐帧能力经过《新世纪福音战士》级别的实际生产验证。

**对标的 Animate 有什么不同？**
Animate 按月收费、绑 Adobe 全家桶；Kinexa 永久免费、全中文、零联网。
